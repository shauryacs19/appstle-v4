# appstle-v4 — context

Appstle marketing site v4 = v3 layout/sections/animations on a light cream canvas with Appstle logo blues; v2-style hero; no glass. Read this file instead of re-scanning the code.
Copied from `../v3` on 2026-10-29 (no restore-points, no git yet).

## Stack
Next 16.4 (App Router, cacheComponents, React Compiler) · React 19.3 · Tailwind v4 · motion 14 · lucide-react · tailwind-merge.
Install on Windows only (`install.cmd` / `npm install`), never from WSL/Linux. `npm run dev` → port 3002.

## Theme
- Tokens `src/styles/tokens.css`: canvas `canvas` #FDFAF4 (page/body), `canvas-2` #F8F2E6 (alt bands), `canvas-line` #ECE3D2 (warm card rings); `cream-*` remapped to the cream scale. Brand from the logo: gradient #219BFB→#0177F2, `brand` #1088F6, ink #2D2D2D; coral #FF8C69 as the accent (hero underline). Fonts: Inter (body/UI), Bricolage Grotesque (`font-display`, widget numbers/UI), Fraunces (`--font-serif`) for all `main` h1/h2 and `[data-serif]` (unlayered rule in globals.css beats utility weights; `.font-sans` opts out). `.text-brand` inside those headings renders italic with the logo gradient.
- Premium direction (2026-10-29, refs: cream/serif editorial boards + HubTub sky hero + ice-blue store page): canvas #FBF8F2, white bands, logo-blue accents; eyebrows are `.eyebrow-line` (line + small caps blue) via `Eyebrow`; blue gradient stat pills.
- Glass is OFF (`data-glass` removed from `<html>`; `glass.css` still imported but inert). v3 doodle line pattern ON across every home section (`.home-pattern` wrapper in page.tsx, `--pattern-alpha: 0.09`).
- Per-app accents (v2-style colour): `lib/accents.ts` `accentVars(id)` overrides `--color-brand*` in a scope — Subscriptions blue, Memberships violet #7357F6, Loyalty coral #F2724B, Bundles green #16A06B, Pickup pink #E2557F. Used on product-card stages/icons/doodles and hero widgets; CTAs stay brand blue.
- Logo: `src/assets/brand/appstle-logo.png` (official lockup, 900px) via `AppstleLogo tone="dark"` (header, mobile nav); light tone keeps the SVG mark.
